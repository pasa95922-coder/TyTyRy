# Game Starter

Godot project for a mobile game.

## Team workflow

1. Do not work directly on `main`.
2. Create a branch for every task: `feature/menu`, `feature/gameplay`, or `fix/name`.
3. Before starting: `git pull origin main`.
4. Before merging, run the game and create a pull request for review.
5. Avoid editing the same Godot scene or script at the same time.

## Security

Do not commit keys, passwords, Android signing files, or release builds. See `SECURITY.md`.
